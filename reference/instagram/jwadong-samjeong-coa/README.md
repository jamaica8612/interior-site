## 사용자와 정한 다음 순서

1. 사용자가 해당 집의 실제 구조 또는 평면도를 제공한다.
2. 현관 위치, 중문의 실제 개폐 방식, 거실·주방·창 방향을 사진과 대조한다. 사진만 보고 평형이나 실제 동선을 확정하지 않는다.
3. 평면도와 실제 사진을 함께 참조해 시작·중간·마지막 장면의 구도를 재생성한다. 시공 형태와 재료를 보존하면서 수직선·노출·화이트밸런스·채광을 정리한다. 실제 시공사진과 재생성된 이미지는 구분해 보관한다.
4. 구조가 맞는 키프레임으로 Flow 영상을 만든다. 닫힌 문 → 실제 개폐 방식으로 열림 → 문턱 통과 → 거실을 향한 자연스러운 이동 → 짧은 정지. 문짝 늘어남, 벽·가구 변형, 구조가 다른 방으로의 전환, 과도한 광각 왜곡을 피한다.
5. 영상 결과를 확인한 뒤 기존 스크롤 렌더러와 실제 시공 포트폴리오에 연결한다. 재생성 영상에는 실제 사진 기반 AI 연출임을 표시한다.

현재 상태: 사진 추출 완료. 사용자 평면도 대기. 재생성·Flow 영상 생성·공개 사이트 변경은 아직 하지 않았다. 기존 Flow는 인앱 브라우저에서 Google 계정 로그인이 풀린 상태이며, 제작 단계에서 기존 계정 접속을 다시 확인해야 한다. Higgsfield 신규 가입은 현재 필요하지 않다.
